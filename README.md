# The Halal Guys — Demo Site

A demo concept site for The Halal Guys — legendary halal street food from 53rd & 6th, NYC. Chicken over rice, beef gyro, and the famous white sauce.

Single self-contained page: `index.html` (HTML + CSS, Google Fonts, no build step).

## Live

https://respondsrehman-lang.github.io/halal-guys-demo/

## Run locally

Open `index.html` in a browser, or:

```
python3 -m http.server 8000
```

then visit http://localhost:8000

## Deploy

Served via GitHub Pages from the `main` branch (repo root).
